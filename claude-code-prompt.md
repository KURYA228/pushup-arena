# Промпт для Claude Code

Скопируй текст ниже целиком и вставь в Claude Code (в папке проекта). Файл `pushup-arena.html` из чата приложи рядом как референс исходной версии.

---

Хочу собрать личное (не публичное) веб-приложение — геймифицированный счётчик отжиманий "Железная Арена". У меня уже есть рабочий прототип на чистом HTML/CSS/JS в файле `pushup-arena.html` — используй его как референс механик и контента (боссы, XP, ранги, достижения, Speed Rush), но пересобери на нормальном стеке и доведи до ума.

## Стек
- Vite + React + TypeScript
- Tailwind CSS
- PWA (manifest + service worker), чтобы можно было "установить" на телефон с домашнего экрана и работать офлайн
- Локальное хранение прогресса через IndexedDB (например, через `idb` или `dexie`) — без бэкенда, всё на устройстве

## Главное отличие от прототипа: нормальный AI-подсчёт отжиманий
В прототипе подсчёт через камеру — это грубая эвристика по разнице яркости пикселей. Хочу нормальную версию:
- Используй **MediaPipe Pose** (или `@mediapipe/tasks-vision` / `@tensorflow-models/pose-detection` с моделью MoveNet) для отслеживания ключевых точек тела в реальном времени через камеру.
- Считай повторение по **углу локтя** (плечо-локоть-запястье) и/или углу тела относительно земли: вниз, когда угол локтя < ~90°, вверх — когда почти выпрямлен (> ~160°), с гистерезисом и минимальным интервалом между повторами (защита от дребезга).
- Добавь калибровку: пользователь встаёт в исходное положение, приложение измеряет базовые углы перед стартом.
- Обязательно оставь ручной режим (кнопка +1/-1) как запасной и для коррекции счёта.
- Наложи на видео скелет ключевых точек (полупрозрачный, для наглядности) во время тренировки.

## Игровые механики (перенести и доработать из прототипа)
1. **Профиль/Дом** — уровень, XP, прогресс-бар до следующего уровня, ранги (Новичок → Боец → Воин → Чемпион → Легенда → Титан), общий счётчик отжиманий, стрик по дням (с логикой "сегодня/вчера/сброс"), сетка достижений.
2. **Боссы** — список из 6+ противников с растущим HP, урон за повтор (обычный/крит), прогресс сохраняется, победа открывает следующего босса.
3. **Speed Rush** — таймер 60 секунд, счётчик повторов, комбо-множитель за быстрый темп, личный рекорд.
4. Всё это должно опираться на единый источник повторений (реальных, из pose-detection, или ручных).

## Качество и UX
- Мобильный форм-фактор, адаптивная вёрстка, поддержка safe-area на iOS.
- Плавные анимации (уровень-ап, урон боссу, победа), но без перегруза.
- Дизайн: тёмная "боевая" тема — используй референс из прототипа (антрацит + янтарный акцент + красный для урона) как отправную точку, но улучшай.
- Код раздели на компоненты и хуки: `usePoseDetection`, `useProfile` (IndexedDB), отдельные компоненты `BossView`, `RushView`, `HomeView`.
- Добавь обработку ошибок доступа к камере и разрешений (permissions), понятные сообщения пользователю.
